Every cross-family provenance mechanism in AE is bounded by one structural fact: the proxy being checked and the team lead checking it are both LLM agents holding unrestricted `Bash` inside a single trust boundary (plugins/ae/agents/workflow/codex-proxy.md:4). The party under scrutiny can write any artifact the scrutinising party would read, which is why the canonical rule is stated as absence-detection and refuses to claim more — receipt presence proves nothing, and a correlator only removes one way of failing to disqualify a verdict (plugins/ae/skills/agent-selection/SKILL.md:350). Judgment, unanchored: the borrowed vocabulary is the hazard, not the mechanism. SLSA, in-toto and RATS all assume an attester that cannot write the verifier's evidence; importing their words onto a check that lacks that property describes a guarantee the system does not hold.

The distinction that keeps the design honest is crash-fault versus Byzantine-fault. A proxy that skips its backend call and emits a plausible correlator is an omission fault, and it is the failure this project has actually observed; a proxy that forges corroborating artifacts is Byzantine, and no check available inside the boundary touches it. The two candidate primitives sit on opposite sides: reading the Codex rollout file is free and validates content but is forgeable with `Bash`, while a resume probe against a claimed thread id is not file-backed — a byte-identical rollout copy under a substituted UUID is rejected as a missing session while the genuine id resumes. Judgment, unanchored: the probe therefore buys authenticity the file read cannot, at the cost of a model call and a mutated thread, and it still cannot show that the resumed session produced the findings being aggregated.

What the mechanism can record is bounded too: the durable failure enum accepts only timeout, connection, rate_limit and quota_exhausted (plugins/ae/scripts/append-cross-family-trace.sh:54), so a verdict disqualified on admissibility grounds has no value that fits it and is written nowhere. Enforcement reach is the second bound. Exactly one wired checkpoint exists — the discuss admissibility filter, which reclassifies an uncorroborated verdict to unavailable before any counting rule sees it (plugins/ae/skills/discuss/SKILL.md:250). Every other statement of the rule is prose beside an aggregation path rather than inside it, and a rule stated beside a state machine does not fire. Judgment, unanchored: a family with no durable per-call artifact cannot reach corroboration at all under this design, so admissibility asymmetry between families is a capability fact rather than a ranking, and any correlator minted by AE itself to close that gap is self-attestation wearing the format of evidence.
