### F-080 — Re-evaluate the Gemini cross-family path — remove, re-host, or generalize (done)

Google discontinued Gemini CLI in favour of Antigravity CLI. AE does not use
Gemini CLI, so the announcement is not the real trigger; it is the occasion. The
real trigger is that AE's Gemini integration is a vendored Node/TypeScript MCP
server that runs `npm install` at every startup, and it is the only reason
Node.js is a dependency of this project at all. On a fresh machine with no Node,
it is the one component that does not come up.
